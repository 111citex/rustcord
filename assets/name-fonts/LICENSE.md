# Display name fonts

The fonts in this folder draw Discord's "Display Name Styles". All are under
the SIL Open Font License 1.1 (https://openfontlicense.org).

- Bangers, BioRhyme, Cherry Bomb One, Chicle, MuseoModerno, Pixelify Sans,
  Zilla Slab, Playpen Sans, Orbitron, New Rocker, Kalam: from Google Fonts
  (github.com/google/fonts, `ofl/`), unmodified.
- Sinistre.ttf (family "Vampyre", © 2023 Jules Durand & Collletttivo) and
  NeoCastel.ttf (family "Medieval", © 2023 Max Lillo): Discord's OFL builds,
  converted from WOFF2 to TTF.
